# 内置技能目录

本目录放**项目自带的技能**(跟 git 走,装哪台机器都一样)。

## 内置 vs 用户技能

| 类型 | 位置 | 谁创建 | 跨机器 |
|---|---|---|---|
| **内置技能** | `项目/skills/`(本目录) | 开发者 | 跟代码走(git) |
| **用户技能** | `~/.agent/skills/` | 用户 / agent | 跟用户数据走(需 rsync) |

同名时**用户目录优先**(用户能覆盖内置)。

## 怎么加内置技能

```bash
mkdir skills/<技能名>
# 写 SKILL.md(frontmatter + 正文)
```

启动 agent 自动扫到,LLM 看到 `/<技能名>` 索引。
